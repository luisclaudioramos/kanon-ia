# Visão Estratégica e Análise de Negócio

## Além do software

[Análise de Negócio](GLOSSARIO.md#analise-de-negocio) avalia todo o fluxo de valor da empresa — não só a funcionalidade sendo pedida — para confirmar que o requisito está alinhado a um objetivo estratégico real, e não é apenas a preferência pontual de quem pediu.

Um requisito pode estar perfeitamente bem escrito (evidência, critério de aceite, escopo delimitado) e ainda assim não valer a pena, se ele não se conecta a nenhum objetivo maior do negócio. A pergunta que a Análise de Negócio força a fazer: **se isso for entregue com perfeição, o negócio melhora em quê, concretamente?**

## Quando aplicar

- Requisitos que vêm de liderança/diretoria, sem passar antes pelo usuário final — vale checar se o objetivo estratégico por trás está claro para quem vai construir, não só para quem pediu.
- Requisitos que impactam mais de uma área — a Análise de Negócio ajuda a identificar quem mais é afetado além de quem pediu.
- Decisões de priorização entre requisitos concorrentes — comparar pelo valor estratégico, não só pela urgência percebida de quem gritou mais alto.

## Risco de pular esta camada

Sem essa visão, é possível entregar exatamente o que foi pedido — literalmente, com critério de aceite verde — e ainda assim não resolver o problema de negócio, porque o pedido original já estava desalinhado do objetivo real. Isso é diferente de um requisito mal escrito: é um requisito bem escrito, mas para o problema errado. Ver também [09-anti-padroes-e-sinais-de-alerta.md](09-anti-padroes-e-sinais-de-alerta.md).
