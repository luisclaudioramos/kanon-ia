# Showcase de Componentes (Storybook)

## Objetivo
Catálogo interativo dos componentes do [design system](03-design-system.md) — cada componente demonstrado com suas variações reais, servindo como documentação viva e como ambiente de desenvolvimento isolado (sem precisar subir a aplicação inteira para iterar num componente).

## Addons de referência
- Acessibilidade (auditoria automática de contraste/ARIA por história).
- Viewport (testar os breakpoints definidos em [Aplicação Frontend](05-aplicacao-frontend-angular.md)).
- Controls/Actions (manipular props e observar eventos emitidos interativamente).

## Convenção
Cada componente publicado no design system ganha um arquivo de "história" correspondente, versionado junto ao componente (não num repositório separado) — mesma lógica de documentação viva de `06-documentacao.md`.
